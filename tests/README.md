# Launcher parity tests

Checks that the native launchers in `hisat2_launcher.c` (`hisat2`,
`hisat2-build`, `hisat2-inspect`) behave like the upstream wrapper scripts
(Perl `hisat2`, Python `hisat2-build` / `hisat2-inspect`). Each test case runs
one command line through both and compares the exit code, stdout, stderr and
every file written. Paths are replaced by tags (`<BIN>`, `<TD>`, `<CWD>`), and
gzip/bzip2 outputs are compared by compression type plus decompressed content.

- `gen_td.py`: writes deterministic synthetic test data (two random
  chromosomes; single-end reads of lengths 100 and 75 plus random reads; paired
  reads; FASTA reads; a FASTQ file with a blank line).
- `parity.py`: the comparison harness. The case list (`CASES`) covers plain,
  gzip, bzip2 and FASTA input, stdin, comma lists, `-c`, attached `-1`/`-2`, the
  read-length check, `--un`/`--al`/`--un-conc`/`--al-conc`/`--al-conc-disc`
  (plain, `-gz`, `-bz2`, `%` / extension / directory targets), `--no-unal`,
  small/large indexes, the error paths, `--verbose`, `--debug`, `--` (wrapper
  options before it, binary options after it, `--log-file`), a read-length
  check that stops at a blank line, paths with spaces and non-ASCII characters,
  index building and inspection.
- `run_parity.sh`: sets everything up and runs the comparison on Linux/macOS.
- `run_extra.sh`: two checks the scripts cannot be compared on, run after
  `run_parity.sh` (re-uses its directory): a debug build (`hisat2 --debug`
  with `hisat2-align-s-debug`, which has assertions on) must align plain, gzip,
  bzip2, stdin, paired and FASTA input exactly like the release binary; and a
  failing write (a file-size limit, as on a full disk) of each output the
  launcher writes itself must give an `(ERR)` message and a nonzero exit code.

## Linux / macOS: launchers vs the scripts

Needs perl, python3, a C compiler, zlib, libbz2, gzip and bzip2. From the tree
root:

```bash
make hisat2-align-s hisat2-align-l hisat2-build-s hisat2-build-l hisat2-inspect-s hisat2-inspect-l
tests/run_parity.sh /tmp/h2parity          # optional 2nd argument: case-name filter
make hisat2-align-s-debug                    # then the extra checks:
tests/run_extra.sh /tmp/h2parity
```

The script copies the binaries next to the upstream scripts (`ref/`, with
`hisat2_read_statistics.py` made executable so the Perl wrapper runs its
read-length check, as in a normal install) and next to freshly compiled
launchers (`launch/`), generates the data and indexes, and runs `parity.py`.

Each case prints `SAME`, `EXPECTED-DIFF` (a known, deliberate difference listed
in `parity.py` with its reason) or `DIFF` with a diff. The exit status is 1 if
any case differs unexpectedly. The expected differences are the ones described
in the main `README.md`: the `@PG` command line for gzip input, `--verbose`
with read files, paths with spaces, and the message when a binary cannot be
started.

## Windows: launcher vs the macOS/Linux launcher

The scripts do not run on Windows, so compare the Windows launcher's results
with those of the launcher on macOS/Linux (which the step above checks against
the scripts):

1. On macOS/Linux, after `run_parity.sh` (re-uses its `launch/` and `td/`):

   ```bash
   python3 tests/parity.py dump /tmp/h2parity/launch /tmp/h2parity/td /tmp/h2parity/dump mac.json
   ```

2. On Windows, build the launchers and binaries (`mingw32-make ARCH=aarch64
   hisat2.exe hisat2-build.exe hisat2-inspect.exe hisat2-align-s ...`, one
   target per call), put them in one folder with their DLLs, copy `td/`
   (generated by `gen_td.py`) and rebuild its indexes there, then:

   ```bash
   python tests/parity.py dump BIN_DIR TD_DIR WORK_DIR win.json
   ```

   For the non-ASCII path case, put a UTF-8 code-page manifest
   (`<activeCodePage>UTF-8</activeCodePage>`) next to each `.exe`, as the
   ngs-tools installer does.

3. Compare: `python3 tests/parity.py cmp mac.json win.json`. Known differences
   come from how the binaries are built (no `--mm` in the Windows usage text,
   `--version` build details, verbose timestamps) and from Windows refusing to
   start a missing binary.
